# YT Searcher — AI Semantic Search for YouTube

**YT Searcher** — полнофункциональное веб-приложение для интеллектуального поиска YouTube-видео и анализа их содержания с помощью AI. Вместо ручного просмотра множества роликов пользователь описывает интересующий вопрос, а система находит релевантные видео, получает их транскрипты и формирует единый структурированный ответ по найденным источникам.

Проект объединяет **поиск, извлечение данных, LLM-анализ, веб-интерфейс и экспорт результатов** в одном рабочем процессе.

## Что умеет приложение

- **Семантический поиск:** преобразует запрос пользователя в подходящие поисковые формулировки и подбирает релевантные ролики.
- **Поиск по ссылке:** поддерживает сценарий работы с конкретным видео или YouTube-каналом.
- **Сбор транскриптов:** автоматически получает текст видео через интеграцию с Supadata API.
- **AI-суммаризация:** анализирует содержание нескольких видео и формирует общую сводку по запросу, с возможностью более подробного ответа.
- **Просмотр источников:** показывает найденные ролики, информацию о них и раскрываемые транскрипты.
- **Экспорт:** копирование результата и сохранение сводки в PDF, DOC и TXT.
- **Адаптивный интерфейс:** отдельная компоновка элементов для десктопа и смартфонов.
- **Аккаунты и подписки:** в проекте предусмотрены авторизация, история и интеграция платных тарифов.

## Как устроен процесс

```text
Запрос пользователя
  → AI-подбор поисковых фраз
  → Поиск релевантных YouTube-видео
  → Получение транскриптов (Supadata API)
  → Объединение и анализ текста (LLM API)
  → Сводка с найденными источниками
  → Экспорт PDF / DOC / TXT
```

## Технологии и архитектура

| Компонент | Технологии |
| --- | --- |
| Frontend | React, JavaScript, CSS |
| Backend | Node.js, Express |
| AI-интеграции | OpenAI / OpenRouter API |
| Работа с YouTube | yt-search, Supadata API |
| Хранение и пользователи | Firebase Authentication, Firestore |
| Монетизация | Интеграция Gumroad |
| Развёртывание | Vercel, Firebase |

**Инженерная часть проекта:** интеграция нескольких внешних API, пакетный сбор и обработка текстовых данных, серверные endpoints, формирование отчётов, работа с пользовательскими аккаунтами и подписками.

## Запуск локально

```bash
git clone https://github.com/Ivan213131314/youndexer.git
cd youndexer
npm install
```

Создайте файл `.env` и настройте необходимые API-ключи и параметры Firebase. **Не размещайте реальные ключи в репозитории и не используйте `REACT_APP_` для секретов**: все ключи внешних сервисов должны оставаться на серверной стороне.

```bash
npm run server  # API: http://localhost:3001
npm start       # React: http://localhost:3000
```

## Основные API endpoints

- `GET /api/search` — поиск видео по запросу.
- `POST /api/batch-search` — пакетный поиск.
- `POST /api/transcript` и `POST /api/transcripts` — извлечение транскриптов.
- `POST /api/summarize-transcripts` — формирование AI-сводки по материалам.
